# Интеграционная проверка, 10–11 октября 2026

Это исторический прогон до удаления `candidates` из ответа. В текущем контракте
список передаётся только на вход, а при уточнениях фронт добавляет сохранённых
кандидатов. Скрипт `smoke_test.py` обновлён под этот контракт.

Endpoint: `POST http://127.0.0.1:8002/extract`, настоящий Uvicorn + SQLite
`ktru.db` из репозитория + локальный LM Studio. Модель `qwen/qwen3.8-27b`,
MLX 4bit, контекст 8192, `LM_STUDIO_REASONING_EFFORT=none`.
Остальные параметры — из `.env.example`.

Заключительный запуск `scripts/smoke_test.py` завершился с кодом 0:

| Запрос | Результат | Время, с |
| --- | --- | --- |
| Молоток с деревянной ручкой 15 см | Длина рукоятки 150 мм; материал рукоятки неизвестен в предоставленном КТРУ | 38,61 |
| Молоток 15 см | Неявная длина рукоятки 150 мм | 32,55 |
| Молоток массой 500 г | Масса молотка 0,5 кг | 32,99 |
| Молоток с гравировкой дракона | Гравировка: «Неизвестная характеристика» | 32,33 |
| Молоток массой не больше 500 г | `unsupported_constraint`; равенство массы не создано | 29,43 |
| Лопата длина 15 см | Выбор между длиной полотна и длиной черенка | 6,79 |

Последний сценарий включает три HTTP-запроса: первичное извлечение, отправку
документа с очищенными вопросами без ответа, затем выбор одного варианта.
Вопрос был восстановлен, выбранная характеристика нормализована, получен
`status: completed`. Повторные запросы обрабатывает Python без обращения к LLM.
Во всех шести сценариях проверено сохранение всех десяти кандидатов.

Время — отдельные наблюдения на этой машине с уже загруженной моделью,
не бенчмарк; возможен эффект кеширования контекста LM Studio.

Также прошёл 81 автоматический тест (`unittest`): контракт, SQLite,
справочник, протокол LM Studio, перевод единиц, ошибки HTTP и stateless-цикл
на разных экземплярах приложения. 4B в этом прогоне не оценивалась.

Это небольшая проверка интеграции. Примеры использовались при настройке prompt,
поэтому не являются независимой оценкой качества. Для измерения точности и
полноты нужна отдельная размеченная выборка, включая другие категории товаров.
