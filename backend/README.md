# Backend

Начальный каркас сервиса подбора характеристик и кодов КТРУ.
Python >= 3.12, FastAPI, Uvicorn, стандартный `sqlite3`, без SQLAlchemy.

## Запуск

Из корня репозитория:

```bash
cd backend
uv sync
uv run uvicorn app.main:app --reload
```

Swagger UI: http://127.0.0.1:8000/docs.
`GET /health` проверяет доступность базы и основных таблиц каталога:
200 при успехе, 503 при недоступной базе или отсутствии таблиц.
Наличие данных, моделей и поисковых индексов пока не проверяется.

## Настройки окружения

- `APP_NAME`: название приложения, по умолчанию `TenderHack KTRU API`.
- `DATABASE_PATH`: путь к SQLite. По умолчанию используется существующая
  `ktru.db` в корне репозитория независимо от рабочей директории.
  Относительный путь из переменной разрешается от текущей рабочей директории.

API открывает каталог только для чтения. Соединения закрываются после использования.
Файл `.env` автоматически не загружается: задавайте переменные в окружении процесса.

## Состояние каркаса

Подключены роутеры analysis, catalog и health; реализован только `/health`.
Остальные модули содержат описание назначения и TODO, JSON-словари пустые.
Загрузка моделей, анализ, поиск, нормализация и импорт ещё не реализованы.
`db/models.py` оставлен в структуре как место для моделей данных без ORM.
Существующие `main.py`, `schema.sql`, `ktru.db` и исходные данные в корне
репозитория сохраняются; перенос импортёра в новый backend предстоит отдельно.

## Контекст задачи из презентации

- Категории: одежда, мебель, инструменты. КТРУ имеет приоритет над примерами СТЕ.
- Из описания нужно извлекать характеристики, сопоставлять значения и единицы,
  постепенно сужать кандидатов до кода КТРУ.
- Ошибки и исправления должны объясняться; при неоднозначности нужны конкретные
  уточняющие вопросы. Следует сохранять связь фактов с исходным текстом.
- Импортировать актуальные выгрузки `nsiKTRUNew_all-actual_*.xml`,
  исключать `nsiKTRUNew_all_not-actual_*.xml`.
- Целевая ОС — Linux. По условиям задачи используются открытые ML-модели
  с суммарным потреблением VRAM для инференса не более 40 ГБ;
  предпочтительны лёгкие модели. Платные поисковые API, внешние API
  проприетарных LLM и low-code/no-code платформы запрещены.
